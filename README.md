# Fruitloop V2

Standalone Android word-puzzle prototype based on V1.

## V2 changes
- Animated letter tiles: flip/reveal animation after each submitted guess.
- Tile pop animation as letters are entered.
- Themed word setting with **Fruit, Animal, Vegetable, Mineral, and Random**.
- Theme selection is remembered locally.
- Offline-only: no network permission, accounts, ads, or analytics.
- Existing scoring, hints, daily rotation, and local best score retained.

## Build without a PC
The project includes `.github/workflows/build-apk.yml`. A GitHub-hosted build can compile the debug APK in the cloud, so a PC is not required.
